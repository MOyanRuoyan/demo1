如何用 Supabase 搭建免费后端服务

发布时间：2026-04-20阅读：128分类：后端开发
Supabase后端无服务器

Supabase 是一个开源的 Firebase 替代品，提供了数据库、认证、存储、实时订阅等功能，而且有免费的额度，非常适合个人项目和小型应用使用。

1. 注册 Supabase 账号

首先访问 Supabase 官网，使用 GitHub 账号登录，创建一个新的项目。

2. 创建数据库表

在 Supabase 控制台中，进入 SQL Editor，创建所需的数据表。例如创建一个用户表：

CREATE TABLE users (
  id UUID PRIMARY KEY DEFAULT uuid_generate_v4(),
  email TEXT UNIQUE NOT NULL,
  name TEXT,
  created_at TIMESTAMP WITH TIME ZONE DEFAULT NOW()
);

3. 配置认证

Supabase 内置了邮箱密码、GitHub、Google 等多种认证方式，只需在控制台中启用即可。

4. 在前端中使用

安装 Supabase JS 客户端：

npm install @supabase/supabase-js

初始化并使用：

import { createClient } from '@supabase/supabase-js'

const supabaseUrl = '你的项目URL'
const supabaseAnonKey = '你的匿名密钥'
const supabase = createClient(supabaseUrl, supabaseAnonKey)

5. 总结

通过以上步骤，你就可以快速搭建一个完整的后端服务，无需关心服务器运维问题，专注于业务逻辑的实现。
